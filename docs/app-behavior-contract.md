# MuseumMuse 主 App 规范

本文件承接 [AGENTS.md](../AGENTS.md) 第 4 章；涉及主 App 交互、缓存、详情、收藏或图片时必须阅读相关小节。标为待实现的条目是需求差距，不是当前能力。

## 4. 主 App 规范

### 4.1 信息架构

- App 主界面以一级页面为入口，并提供可从一级页面进入的收藏夹页：
  - 一级页面：博物馆列表
  - 收藏夹页面：按博物馆分组查看已收藏展品
  - 二级页面：某个博物馆的展品列表
- 点击二级页面中的展品后，进入展品详情页。
- 点击收藏夹页面中的展品后，同样进入对应展品详情页。

### 4.2 一级页面

- 展示已支持的博物馆列表。
- 首页按国家分组展示博物馆：
  - `中国` 分组固定显示在最上方
  - 同一国家内的博物馆继续保持当前支持顺序
- 首页每个博物馆卡片左侧都需要展示对应 logo：
  - logo 放在统一的浅色圆角容器中
  - 名称和副标题继续保持当前中文文案，不因 logo 接入而改变
  - 首页已按国家分组时，卡片副标题只显示城市，不重复显示国家
- 首页支持下拉刷新；手动刷新时需要以 `network-only` 重新请求 `/v1/museums/metadata`，并继续把成功结果写入 App Group metadata 快照。
- 首页不提供延迟测试开关、延迟结果行或下拉测速入口，也不在进入首页时发起测速请求。
- App 冷启动时需要立即发起一次独立的轻量联网请求，用于触发系统联网权限提示；该请求不写入展品搜索、详情或 Widget 缓存。
- 新安装 App 首次联网时，如果首页 metadata 请求在系统联网权限确认前失败，系统提示关闭并使 App 重新进入 `active` 后，首页必须在仍无可见 metadata 时自动以 `network-only` 重试，不得要求用户重启 App；若原请求尚未结束，重试应排队并在原请求结束后串行执行。
- 右上角需要同时提供：
  - 收藏夹图标入口
  - 设置图标入口
- 首页不再提供博物馆拖拽排序或排序模式；右上角固定显示收藏夹和设置入口。
- 首页设置页用于全局设置：
  - 小组件自动刷新间隔可选：`关闭`、`1小时`、`3小时`、`6小时`、`12小时`、`24小时`
  - 小组件自动刷新间隔默认值为 `24小时`；用户明确保存为 `关闭` 时仍保持关闭
  - 小组件自动刷新还需要提供 `开始时间` 和 `结束时间`，默认分别为 `00:00` 和 `23:00`
  - `开始时间` 与 `结束时间` 以单独的设置行展示，点击后进入时间选择，不直接在设置页内联展开选择器
  - 时间选择页面使用不透明背景，不展示右下角的当前时间预览
  - `开始时间` 与 `结束时间` 只支持选择整点
  - `开始时间` 与 `结束时间` 按每日同日时间窗生效，不支持跨午夜；若结束时间早于开始时间，则结束时间需要自动归齐到开始时间
  - 设置页需要根据当前配置显示“今日自动刷新时间”明细；自动刷新关闭时显示已关闭状态
  - “今日自动刷新时间”文案需要居中；各时间点按多行多列等距排布，不使用顿号拼接，并使用等宽字体
  - 设置页需要支持将 App 配置导出为 JSON 文件，并支持从 JSON 文件导入恢复
  - 配置导入 / 导出范围包括全局设置、详情页全局字号、各馆二级页显示模式、分类设置、动态 source 选择、收藏，以及按博物馆记录的 Widget 已刷新展品历史
  - 配置导入后需要刷新主 App 内存状态，并触发 Widget timeline 重新加载
- 首页设置页不展示翻译相关项目。
- 详情页翻译能力继续保留：
  - 不再提供腾讯云、MiniMax 或其他第三方翻译引擎的选择、凭证填写、测试或清空入口
  - 详情页右上角翻译按钮使用 `TranslationSession` 触发应用内批量翻译
  - 翻译结果直接在当前详情页原位替换原文，不弹出独立翻译页
  - 首次翻译成功后支持在原文与译文之间切换
  - 若系统翻译语言包未准备好，只提示，不主动弹出系统下载页
  - App 当前最低支持系统版本为 `iOS 18`
- 当前博物馆文案要求：
  - 主标题显示：`大都会艺术博物馆`
  - 副标题显示：`纽约`
  - 主标题显示：`东京国立博物馆`
  - 副标题显示：`东京`
  - 主标题显示：`奈良国立博物馆`
  - 副标题显示：`奈良`
  - 主标题显示：`中国国家博物馆`
  - 副标题显示：`北京`
  - 主标题显示：`上海博物馆`
  - 副标题显示：`上海`
  - 主标题显示：`吉美国立亚洲艺术博物馆`
  - 副标题显示：`巴黎`

### 4.3 二级页面

- 二级页面展示该博物馆的展品流。
- 布局形式为瀑布流。
- 页面必须适配最新 iPhone 全面屏，不允许出现上下大黑边。
- 页面必须支持正常滚动，不允许出现上滑后无法继续触发加载的问题。
- 二级页面需要提供单独的“页面设置”入口。
- 当前二级页面中的以下能力需要放入“页面设置”中统一管理：
  - 视图切换
  - 类别筛选

#### 4.3.1 页面设置交互

- 页面设置中的“显示”需要支持记忆功能。
- 页面设置中的“类别筛选”需要支持多选。
- 用户点进页面设置后，当前已生效的“显示”选项和类别勾选状态必须在首屏立即渲染出来：
  - 不允许先显示默认值、空态或未勾选状态，再延迟补刷成真实配置
  - 打开设置页时看到的内容，应等于该博物馆当前实际生效的配置
- 类别筛选默认状态为：
  - `全部`
  - 等价于该博物馆下所有类别都被选中
- 类别筛选需要按博物馆分别记忆用户上次的选择结果。
- “显示”也需要按博物馆分别记忆用户上次的选择结果。
- 用户在页面设置中做出的修改，不允许边改边立即生效。
- 只有当用户点击页面设置右上角的 `完成` 按钮后：
  - 显示设置才真正生效
  - 类别筛选才真正生效
  - 如类别发生变化，才重新按新类别进行数据拉取和显示
- 数据源选择器只在 metadata 的 `sources.count > 1` 时显示：
  - 大都会提供 `全部展品` / `在展展品`，默认 `met_all`；在展筛选由后端 `met_on_view` 完成。
  - 奈良提供 `馆方数据源` / `ColBase`，默认 `official`。
  - 数据源、分类与显示草稿均只在点击 `完成` 后生效；直接关闭不保存。
  - 切换草稿数据源时，分类重置为该源的 `全部`。
- 如果用户没有点击 `完成`，而是直接通过下滑手势关闭页面设置：
  - 本次设置修改不生效
  - 不允许写入记忆状态
  - 二级页面继续保持进入设置前的显示和筛选状态
- 如果用户取消全部品类勾选后点击 `完成`：
  - 页面设置保持打开，不保存空选择
  - 提示固定为：`当前未勾选任何品类，请至少勾选一个品类后再完成。`
- 如果已勾选品类的后端请求成功但返回 `0` 件展品：
  - 二级页必须显示 `所选品类暂无展品`
  - 说明文案固定为：`当前勾选的品类没有可展示的展品，请重新选择品类。`
  - 页面内提供 `重新选择品类` 按钮并打开页面设置
  - 不允许把这种空结果显示成网络 `加载失败`，也不应只提供无效的重复重试

#### 4.3.2 数据加载

- 进入二级页面时，不要一次性抓取所有详情数据。
- 首次只加载少量展品：
  - 当前约定为 `10` 个。
- 后续继续浏览时，滚动到底部后继续上滑加载下一批。
- 到达底部后，不允许自动继续加载下一批。
- 底部加载更多的交互需要对齐顶部 `refreshable` 的手感：
  - 先继续上滑，超过阈值后进入“松开即可加载下一批”状态。
  - 只有用户松手后，才真正触发下一批加载。
- 每次增量加载数量：
  - 当前约定为 `10` 个。
- 每批只发一次 `limit=10` 的后端列表请求，响应已含完整展品字段；去重或空结果后不额外追拉，不再逐件请求官网详情。
- 下拉刷新时：
  - 重新刷新二级页内容。
  - 重新走首批加载逻辑。
  - 刷新过程中直接进入二级页内联的 `正在加载展品...` 状态，不再回退到独立的 `正在加载展品...` 全屏界面。
  - 刷新中的首批加载提示出现时，屏幕上已经渲染出的展品卡片仍需保留，待新首批结果完成后再整体切换。
- 六馆均使用同一后端分页链路，客户端不预拉官网候选池；离线 crawler 的分页和抓取预算另见数据接入规范。

#### 4.3.3 排序与展示

- 主 App 二级页固定按随机顺序展示展品。
- 二级页面切换到列表视图时，展品卡片中不显示博物馆名称。

#### 4.3.4 缓存与性能

- 不要每次进入二级页面都重新刷新。
- 同一次 App 运行期间，返回再进入二级页面时应复用缓存数据。
- 需要尽量减少首次进入的等待时间。
- 当前 `ArtworkFeedCache` 只保存同一次 App 运行期间的内存快照，按馆、source、分类和后端 `dataVersion` 隔离；其中保留 cursor、seed 和已加载 ID，供返回页面后继续分页。
- `MuseumMetadataStore` 的 App Group 快照、用户设置、收藏和 Widget 状态另行持久化，不等同于页面缓存。
- 原先要求的“重启 App 后恢复展品流本地缓存”尚未实现，保持为待实现需求；不能把内存缓存或 URLSession 协议缓存描述成页面磁盘持久化。
- 后端列表返回后先渲染文字；卡片图片按 URL 异步加载，不等待整批图片下载完成。

#### 4.3.5 日志

- 主 App 默认不显示左下角请求日志悬浮按钮。
- 在全局设置页连续点击 `App 版本` 行 `5` 次后，才显示该日志按钮，并在全局设置页 `关于` 下方新增 `隐藏日志显示` 按钮。
- 点击 `隐藏日志显示` 后，应立即隐藏左下角日志按钮，同时隐藏 `隐藏日志显示` 按钮本身；再次显示需要重新连续点击版本号 `5` 次。
- 页面内加载日志和请求日志的时间戳需要精确到毫秒级。
- 当前页面日志覆盖生效类别、首批 / 下一批后端请求、返回数量、是否还有后续数据、空态和失败原因；不再要求输出 Met 全量 `objectIDs` 抓取日志。
- 缓存恢复路径目前没有专门的命中 / 未命中日志；如需补齐，应在缓存层实现后再记录为已支持。

#### 4.3.6 图片

- 某些展品图片因网络问题加载失败后，网络恢复时需要支持重新加载。
- 不能出现“某张图失败后永远不再重试”的情况。

### 4.4 展品详情页

- 点击展品后进入详情页。
- 详情信息通过服务端详情接口抓取；官网页面解析、大都会概述兜底、国博 / 上博 HTML 清洗等逻辑前移到离线爬虫。
- 详情页不显示副标题；艺术家需要作为独立字段展示。
- 详情页右上角需要提供收藏按钮：
  - 未收藏时显示 `star`
  - 已收藏时显示 `star.fill`
  - 点击后在收藏 / 取消收藏之间切换
- 详情页右上角需要提供分享按钮：
  - 图标使用 `square.and.arrow.up`
  - 点击后对当前展品详情页生成一张长截图
  - 截图不包含顶部导航和操作按钮，但需要包含当前详情页中尚未滚动到的正文内容
  - 生成截图后先弹出一个简单预览，再进入系统分享页面
  - 预览页默认固定半屏高度，不提供拉高或改尺寸交互
  - 预览页中的截图需要完整按比例展示，不使用滚动查看
  - 系统分享页面继续以该图片作为分享对象
  - `DailyMuseum/Info.plist` 需要继续声明 `LSApplicationQueriesSchemes=weixin`，用于分享链路中的微信可用性诊断
  - 修改分享截图渲染或预览确认流程时，需要同步维护 `DailyMuseumTests/CoreLogicTests.swift` 中的分享单元测试
- 详情页右上角操作较多时，分享和字号调整需要收纳进显式的 `更多` 菜单；`AI`、官网、翻译、收藏和 `更多` 需要保持一级可见，不能被系统自动溢出挤掉。
- 详情页右上角一级操作图标需要使用自适应尺寸：
  - 紧凑屏幕使用较小基准尺寸
  - 常规宽度使用稍大基准尺寸
  - 尺寸继续跟随系统 Dynamic Type 缩放
- 支持翻译的详情页右上角需要继续提供翻译按钮：
  - 点击后使用 `TranslationSession` 批量翻译当前详情页已展示的标题、介绍和字段
  - 翻译结果直接替换当前详情页正文，不弹出独立翻译页
  - 首次翻译成功后，按钮需要支持在原文与译文之间切换
  - 若系统翻译语言包未准备好，只展示提示，不弹出系统下载页
  - 不再在 App 内维护腾讯云、MiniMax 或其他第三方翻译引擎配置
  - App 当前最低支持系统版本为 `iOS 18`
- 详情页 `更多` 菜单中需要提供字号调整操作：
  - `更大字号` 使用 `plus.magnifyingglass`
  - `更小字号` 使用 `minus.magnifyingglass`
  - 不提供恢复默认字号操作
  - 点击 `更大字号` 或 `更小字号` 后，`更多` 菜单不能自动收起，需要允许用户连续调整字号
  - 字号调整是全局持久化配置，影响所有博物馆的所有展品详情页，App 重启后仍保留，并随配置导入 / 导出迁移
  - 字号调整不影响首页、二级页、收藏夹或 Widget
- 详情页右上角需要提供 `AI` 按钮：
  - 图标使用 `apple.intelligence`
  - 当前仅在该展品存在官网原始链接时显示
  - 点击后直接调用快捷指令 `DoubaoMuseum`
  - 传入文本固定为：`介绍一下这个展品：当前详情页官方网页链接`
  - 若快捷指令返回 `未找到快捷指令`，则提示用户安装快捷指令，安装入口固定打开：`https://www.icloud.com/shortcuts/50a57de8c0884898a895556c3e8b01b5`
  - 若快捷指令返回 `该App无法打开` 或 `the app could not be opened`，则提示用户安装 `豆包` App，安装入口固定打开：`https://apps.apple.com/cn/app/id6459478672`
- 收藏状态需要在本地持久化保存，App 重启后仍保留。
- 详情页至少展示：
  - 标题
  - 作者
  - 年代
  - 材质
  - 尺寸
  - 类别
  - 文化
  - 国家
- 详情页中的标题、介绍、字段文字和版权文字需要支持自由选中文字，不是只支持整段复制。
- 详情内容底部需要显示版权声明，格式固定为：
  - `©XX博物馆 版权所有`
  - 版权声明在底部独立展示，并水平居中
- 中国国家博物馆、上海博物馆等中文数据源中的详情文字在做 HTML 实体与标点清洗时，需要优先输出中文标点：
  - 引号使用中文引号
  - 破折号使用中文破折号
  - 省略号使用中文省略号
- 详情页支持跳转到官网原始链接。
- 点击详情页主图后，需要进入全屏预览页。
- 全屏预览页需要支持：
  - 双指缩放
  - 单指上下滑动连续缩放；连续缩放时需要保持触点锚定，不能出现画面抖动或回跳到原始尺寸
  - 缩放后的拖动查看
  - 跟随手机横竖屏旋转
  - 保存到系统相册

### 4.4.1 收藏夹页

- 收藏夹页从首页右上角的收藏夹图标进入。
- 收藏夹页按博物馆分组展示已收藏展品。
- 收藏夹中的展品卡片样式、宽度、间距需要对齐对应博物馆二级页的列表模式，不允许继续使用额外的系统列表 inset 把卡片压窄。
- 分组顺序需要跟随首页当前 metadata 分组和 `sortOrder` 顺序。
- 每个分组内的展品按收藏时间倒序排序。
- 收藏夹页点击展品后，需要进入对应展品详情页。
- 当前 source 切换不影响已经收藏的文物：
  - 收藏夹不按当前 source 过滤
  - 已收藏的不同 source 展品都必须继续显示
  - 点击收藏夹中的展品时，当前 `ArtworkReference` 不传 source，后端通过唯一 `(museum_id, object_id)` 解析到数据源；收藏的 artwork 虽保存 source，详情 loader 当前不读取它
- 收藏夹页中的展品需要支持左滑删除，左滑删除等价于取消收藏。
- 收藏夹列表左滑删除后，同一展品详情页右上角星标状态也必须同步为未收藏；反过来，在详情页取消收藏后返回收藏夹时，对应卡片也必须立即消失。
- 取消收藏可通过收藏夹列表左滑删除，或通过详情页右上角星标完成。

## 10 组小组件入口

所有构建统一提供 10 组静态 Widget，使用 `StaticConfiguration` / `TimelineProvider`。主 App 设置 → 小组件 →“分组与展示博物馆”可分别为第 1–10 组选馆；默认所有博物馆，单馆选项只来自 metadata 中支持 Widget 的馆并沿用其排序。每组支持小、中、大及 iOS 27 的 `systemExtraLargePortrait` 竖向超大尺寸。桌面添加时选择对应组，同组各尺寸共享内容，组间独立；即使两组选同馆也不得共享刷新任务或覆盖对方内容。桌面 Widget 内容不显示组号，组名仅在添加小组件与主 App 分组设置中用于选组。

组 1 保留原 `DailyMuseumWidget` kind 和 `widget.compatibilityScope.v1` 偏好，原有桌面小组件及选馆设置自动归入组 1；组 2–10 使用 `.group<n>` kind/偏好后缀。共享状态键为 `compat:<组号>|<scope>`，与尺寸无关；迁移旧 scope 状态至组 1 时保留其展品图片。选馆立即保存、只重载对应 kind，并通过既有 network-only 链路刷新该组当前桌面配置。没有该组桌面实例时不发起展品请求；清理旧状态并取消主 App 中不再属于当前配置的任务。预览和历史状态不代表实际桌面实例。

桌面刷新按钮使用 `Button(intent:)`，传入当前组号，由 `WidgetRefreshIntent` 在 Widget extension 内执行，`openAppWhenRun=false`，不拉起主 App；必须等待 `WidgetManualRefreshRunner` 完成共享状态写入后返回。按钮 label 保留 44 × 44 pt 矩形点击区。兼容链接 `dailymuseum://widget/refresh?group=<1...10>` 仍打开首页并通过 `WidgetManualRefreshRunner` 刷新指定组；缺少 group 的旧链接归入组 1，重复/越界/非法 group 不刷新。手动和自动入口都从共享偏好读取该组选馆，不使用 AppIntent 选馆配置（intent 仅传组号）。展品主体继续使用既有详情深链接。

全局自动刷新时间规则、馆内 source/类别、network-only 候选推进和降采样约束保持适用；每组独立保存下一次自动计划。已展示历史仍按博物馆共享，避免不同组重复命中同一展品。配置导入导出包含全部 10 组选馆项。缺失/非法值、metadata 已移除或不支持 Widget 的馆回退全部；暂缺 metadata 时保留合法已存标识。当前发布要求见 [验证与交付](verification-and-delivery.md)，历史真机覆盖范围见 [历史 OTA 文档](ios-adhoc-ota.md)。
