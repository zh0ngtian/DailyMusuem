# DailyMuseum

## 项目简介

`DailyMuseum` 是一个 iOS App，用于展示博物馆展品，并提供配套的小组件体验。

当前第一版聚焦 `大都会艺术博物馆`，用户可以在 App 中浏览展品流、查看展品详情，并通过桌面小组件快速查看和打开当前推荐展品。
当前已扩展支持 `东京国立博物馆` 与 `中国国家博物馆`。

## 当前能力

- 支持博物馆列表入口，当前已接入：
  - `大都会艺术博物馆`
  - `东京国立博物馆`
  - `中国国家博物馆`
- 支持两级浏览结构：
  - 一级页面选择博物馆
  - 二级页面以瀑布流展示展品
- 支持展品详情页，展示标题、年代、材质、尺寸、部门、文化、国家、馆藏等信息
- 支持展品数据通过 API 获取
- 支持二级页分页加载、下拉刷新和缓存复用
- 支持展品随机展示与按 `objectID` 顺序展示切换
- 支持二级页加载日志展示
- 支持图片失败后的自动重试
- 支持桌面小组件：
  - `小`
  - `中`
  - `大`
- 支持三种尺寸小组件在同一刷新周期内显示同一件展品
- 支持小组件手动刷新
- 支持小组件图片裁剪铺满展示
- 支持在小组件左下角展示展品名称和年代
- 支持点击小组件进入 App 内对应展品详情页
